# go-litenetlib

A Go implementation of [LiteNetLib](https://github.com/RevenantX/LiteNetLib), the reliable UDP networking library for .NET, aiming to stay consistent with the original.

Target version: [LiteNetLib v0.8.3](https://github.com/RevenantX/LiteNetLib/tree/v0.8.3). Compatibility is only guaranteed with clients built on this version.

## Scope

- **Server**: the only side implemented by this library.
- **Client**: not planned. Use the .NET LiteNetLib client to connect.

## Installation

```sh
go get github.com/choi-jungwoo/go-litenetlib
```
